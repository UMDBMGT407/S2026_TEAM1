Manage Users Page – allows admins to view, add, edit, and delete users from the database.
Actions Implemented:
* Read (SELECT):
Displays all users in a table using data pulled from MySQL through a Flask route.
* Create (INSERT):
“+ Add New User” opens a form to enter user details. Data is sent to the backend and added to the database.
* Update (UPDATE):
“Edit” opens a pre-filled form where admins can update user information, which is then saved to the database.
* Delete (DELETE):
“Delete” removes a user after a confirmation prompt.
Additional Features:
Includes a search bar to filter users and demonstrates full frontend and backend integration using Flask and MySQL.
